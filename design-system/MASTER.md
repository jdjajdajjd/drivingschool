# Vroom Design System, кабинет ученика как источник правды

Главный стиль проекта берётся из текущего личного кабинета ученика.

## Сцена
Мобильный сервис для ученика и директора автошколы. Используют на телефоне быстро, часто на ходу, без желания разбираться в сложной системе. Нужен чистый светлый app-style, не сайт-шаблон и не тёмная тема.

## Основные токены
- Фон страницы: `#F5F6F8`
- Карточки: `#FFFFFF`
- Текст главный: `#050609`
- Текст вторичный: `#8B8D94`
- Текст тихий/иконки: `#B8BABF`
- Граница карточек: `#EBECF0`
- Основной акцент/CTA: `#1F2BD8`
- Мягкий акцент: `#EEF0FA`
- Успех: `#14934A` / `#EAF6F0`
- Ошибка: `#FF3155` / `#FFEDEF`

## Компоненты
- Страница: мобильная ширина `max-width: 430px`, фон `#F5F6F8`.
- Карточки: белые, радиус `24px`, тонкая граница, почти без тени.
- Кнопки: основная синяя, радиус `18px`, высота 50-56px на важных действиях.
- Вторичные кнопки: белые или `#F7F8FA`, граница `#EBECF0`.
- Навигация: нижняя мобильная, активный пункт синим.
- Тёмный цвет: только как контрастный блок, не тема.

## Запрещено
- Возвращать тёмную тему или переключатель темы.
- Смешивать тёплый beige/copper стиль с кабинетом ученика.
- Делать разные палитры для лендинга, школы, записи и админки.
