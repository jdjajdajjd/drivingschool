## Что сделали в этой итерации

Полный редизайн `src/pages/SchoolPage.tsx` под уровень конкурента "Хочу Водить".
Бизнес-логика не менялась — только UI.

### 1. Расписание (ScheduleOverview) — major redesign

**Было:** горизонтальный скролл маленьких карточек-кнопок с временем.

**Стало:** вертикальный список слотов как в "Хочу Водить":
- Каждый слот — карточка с левым цветным акцентом (синий = свободно, зелёный = моё, серый = занято)
- Время как диапазон: `07:00 – 08:00` (вычисляется через `addMinutesToTime`)
- Фото инструктора + имя + филиал
- Бейджи `Свободно` (зелёный) / `Вы записаны` (синий) / `занято` (серый)
- Кнопка "Записаться" прямо на карточке
- Фильтры: филиал, категория, только свободные

Новый хелпер: `addMinutesToTime(time, minutes)` — вычисляет конец занятия.

### 2. Аватарка — загрузка файла

**Было:** `<Input label="Аватарка" placeholder="Ссылка на фото">` — поле URL.

**Стало:**
- Кликаешь на аватар → открывается `<input type="file" accept="image/*">`
- Иконка камеры поверх аватара
- Функция `compressAvatar(file)`: canvas center-crop → 240×240 → JPEG 82% → base64
- Хранится в `form.avatarUrl` как dataURL, отправляется в Supabase

### 3. Смена филиала — новый флоу

**Было:** `<Textarea label="Запрос на смену филиала">` — произвольный текст.

**Стало:**
- Кнопка "Сменить филиал" с ChevronRight
- Открывает `<BranchChangeModal>` — модал с bottom sheet:
  - Список всех филиалов с radio-selection
  - Кнопка "Подать заявку" (задизейблена пока не выбран другой филиал)
  - Кнопка "Отмена"
- После отправки: `profile.pendingBranchId` + `profile.branchChangeRequestedAt` сохраняются
- В профиле и кабинете: amber-плашка "⏳ Заявка на смену филиала — ожидает подтверждения"
- Кнопка смены скрывается если `pendingBranchId` установлен

Новое поле в `StudentProfile`: `pendingBranchId?: string`

### 4. StudentDashboard — redesign

- Аватар 56×56, `rounded-2xl`
- Ближайшее занятие — карточка с брендовым цветным фоном, белый текст
  - Крупное время с диапазоном (`formatDate + addMinutesToTime`)
  - Фото инструктора
  - Кнопки "Записаться" (белая с брендовым текстом) и "Расписание" (прозрачная/белая)
- Pending branch notice — amber в шапке профиля

### 5. SchoolHome — redesign

- Hero card: `rounded-3xl`, `shadow-sm ring-1 ring-slate-200/60`
- Заголовок `text-2xl font-bold`, описание `text-sm`
- Большая кнопка "Записаться" — кастомная (не Button компонент), полная ширина, брендовый цвет
- Stats strip — внутри того же белого card, снизу с `divide-x`
- Инструкторы: `Avatar size="lg"`, категориевые бейджи, ближайший слот справа
- Категории: `text-2xl font-black` для кода, красивая сетка
- Филиалы: иконка MapPin в белом кружке

### 6. Booking flow — visual refresh

- Все шаги в `rounded-3xl`
- StepHeader: градиентная полоса прогресса (`from-blue-500 to-blue-600`)
- Шаг category: большие карточки с `text-2xl font-black` для кода
- Шаг branch/instructor: стрелка ChevronRight, avatar size lg
- Шаг date: чекбокс выбора с иконкой Check
- Шаг time: список внутри rounded-2xl card, каждое время — строка с кружком-чекбоксом
- Шаг review: карточки слотов с иконкой Clock
- Шаг profile: иконка CheckCircle2 emerald, без поля avatarUrl (убрано)

### 7. LoginPanel — cleaned up

- Кастомная кнопка "Войти" вместо Button компонента (h-13 — тот же высокий стиль)
- Визуал однороден со всем остальным

### 8. Bottom nav — redesign

- 3 зоны: Главная | Расписание | центральная круглая кнопка (Записаться / Войти)

### 9. Цветовая схема
