# Общее описание интерфейса

Мобильное приложение для ученика автошколы. Интерфейс выполнен в стиле современного iOS-приложения: светлый фон, крупная жирная типографика, большие скруглённые карточки, минимум декоративных элементов, много воздуха, яркий синий как основной акцентный цвет.

Основной визуальный характер: простой, плотный, крупный, уверенный. Дизайн не тонкий и не “воздушный SaaS”, а скорее мобильный сервис с крупными интерактивными зонами.

---

# Размер экрана и сетка

Ориентир — вертикальный мобильный экран формата iPhone, примерно:

```txt
Ширина: 390–393 pt
Высота: 844–852 pt
```

Основная сетка:

```txt
Горизонтальный отступ экрана: 16 px
Отступ между крупными блоками: 16–24 px
Отступ внутри карточек: 20–24 px
Радиус карточек: 20–24 px
Радиус маленьких элементов: 12–16 px
Радиус кнопок: 16–20 px
```

Фон почти на всех экранах:

```txt
Page background: #F5F6F8 / #F6F7F9
Card background: #FFFFFF
Primary blue: #1E2BD8 / #1C2CCB
Text black: #050609 / #07080B
Secondary gray: #8B8D94
Light gray text: #B6B8BD
Border gray: #E5E7EC
Divider gray: #E3E4E8
```

# Типографика

Шрифт похож на системный iOS: `SF Pro Display / SF Pro Text`, либо очень близкий системный sans-serif.

Общий стиль текста — крупный, жирный, с плотной посадкой.

```txt
H1 / главный заголовок экрана:
- 42–48 px
- font-weight: 800–900
- color: почти чёрный
- line-height: 1.05–1.15

H2 / крупный заголовок секции:
- 30–36 px
- font-weight: 800
- line-height: 1.1–1.2

H3 / заголовок карточки:
- 24–28 px
- font-weight: 800
- line-height: 1.15–1.25

Основной текст:
- 18–22 px
- font-weight: 700–800

Вторичный текст:
- 17–20 px
- font-weight: 700
- color: #8B8D94

Мелкий текст:
- 12–15 px
- font-weight: 600–700

Текст кнопок:
- 20–24 px
- font-weight: 800
```

Почти весь интерфейс использует жирные начертания. Тонкого текста почти нет.

# Общие карточки

Основной строительный элемент интерфейса — белая карточка.

```txt

Border-radius: 20–24 px

Shadow: отсутствует или очень слабая
Border: чаще отсутствует, иногда тонкий #EBECF0
```

Карточки крупные, визуально мягкие, без жёстких линий.

# Визуальный язык и детали

Интерфейс использует очень крупные заголовки, особенно на главных экранах. Текст почти всегда жирный. Даже второстепенные подписи имеют вес 700–800.

Главные цвета:

```txt
Синий: основной action/accent
Зелёный: свободно, успешно, доступное занятие
Красный/розовый: просрочка, долг, уведомления
Серый: вторичная информация
Белый: карточки
Светло-серый: общий фон
```

Скругления очень заметные:

```txt
Маленькие элементы: 12–16 px
Средние карточки/кнопки: 18–22 px
Крупные карточки/sheets: 24–28 px
Круглые элементы: 999 px
```

Тени почти отсутствуют. Разделение создаётся фоном, белыми карточками, мягкими границами и скруглением.

Иконки:

```txt
Стиль: outline / line icons
Stroke width: 2–2.5 px
Active icon color: #1F2BD8
Inactive icon color: #B8BABF
System icons: black или gray
```

Иллюстрации в разделе “Теория” — 3D/изометрические, яркие, с округлыми формами, расположены в правом нижнем углу карточек и частично занимают нижнюю часть.

# Общая композиция приложения

Приложение выглядит как набор крупных карточек на светло-сером фоне. Основной контент почти всегда расположен с отступом 16 px от краёв. Навигация внизу всегда белая, плавающая, с большими скруглёнными верхними углами.

Интерфейс не использует мелкие таблицы, плотные списки или тонкую типографику. Все действия должны быть крупными и хорошо нажимаемыми. Карточки воспринимаются как отдельные физические блоки. Главные данные показываются максимально крупно: время занятия, сумма оплаты, название раздела, имя пользователя, название экрана.
